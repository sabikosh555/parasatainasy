# ҚызПУ · Парасат айнасы

«Парасат апталығы» ашылуына арналған қазақша фото-интерактив. Қатысушы камераға түседі, ойын болжамын ашады және өз фотосы бар сторис карточкасын сақтайды.

## Мүмкіндіктер

- ҚызПУ логотипі, жасыл-алтын түстер және үлкен экранға ыңғайлы интерфейс.
- Үш секундтық санақ соңында нақты кадр түсіру.
- Қазақша 32 заманауи ойын болжамы.
- Фото, есім, болжам және шағын тапсырма бар 1080×1920 PNG карточкасы.
- Карточканы алдын ала көру және болжамды өзгертпей қайта фотоға түсу.
- Камераға балама: құрылғыдан фото таңдау.
- «Келесі қатысушы» батырмасы алдыңғы фото мен есімді тазартады.
- Толық экран және қалауыңызша дыбыс.

## GitHub-қа жүктеу

1. ZIP архивін компьютерде ашыңыз.
2. GitHub-та жаңа репозиторий жасаңыз. Мысалы: `parasat-ainasy`. GitHub Free арқылы сайтты ашық жариялау үшін репозиторийді **Public** етіп таңдаңыз.
3. Репозиторийде **Add file → Upload files** тармағын ашыңыз. Бос репозиторийде **uploading an existing file** сілтемесі көрсетілуі мүмкін.
4. Архивтің ішіндегі файлдарды жүктеңіз. **`index.html` репозиторийдің ең жоғарғы деңгейінде тұруы керек.** ZIP файлының өзін немесе сыртқы папканы жүктемеңіз.
5. Файлдарды негізгі `main` тармағына сақтап, өзгерісті бекітіңіз.

## Сайтты GitHub Pages арқылы ашу

Репозиторийдегі **Settings → Pages** бөліміне кіріңіз.

| Баптау | Таңдалатын мән |
| --- | --- |
| Source | Deploy from a branch |
| Branch | main |
| Folder | / (root) |

**Save** батырмасын басыңыз. Жариялау аяқталған кезде осы беттегі **Visit site** батырмасы арқылы сайтты ашыңыз. GitHub құжаттамасына сәйкес, алғашқы жариялау 10 минутқа дейін созылуы мүмкін.

Егер тек кодты GitHub-та сақтағыңыз келсе, Pages қадамын орындау міндетті емес.

## Қолдану

1. Жарияланған HTTPS сайтты браузерде ашыңыз.
2. **Камераны қосу** батырмасын басып, браузердің камера рұқсатын беріңіз. Қаласаңыз, есімді енгізіңіз.
3. **Түсіріп, болжамды ашу** батырмасын басыңыз. Санақ аяқталғанда бір кадр түсіп, экранда қалады.
4. **Карточканы көру** арқылы нәтижесін қараңыз. Фото ұнамаса, **Фотоны қайта түсіру** батырмасын пайдаланыңыз: болжам өзгермейді.
5. **Фото + болжамды сақтау** батырмасы PNG файлын жүктейді.
6. **Келесі қатысушы** батырмасымен жаңа адамға ауысыңыз.

Камера қолжетімсіз болса, **Фото жүктеу** арқылы құрылғыдан сурет таңдаңыз. Демо режимінде фотомен сақтау үшін сурет қосу ұсынылады.

Пернелер: **F** — толық экран; **Space** — бастау немесе келесі қатысушы. Мәтін енгізу кезінде бұл пернелер әдеттегі қызметін атқарады. Фокустағы батырма Space басылғанда өзінің әрекетін орындайды.

## Фото туралы

Фото мен есім осы браузер бетінің жадында өңделеді, серверге жіберілмейді. Камера кадры 4:5 пішіміне ортасынан қиылып, айнадағыдай көрсетіледі. Сақтау кезінде қайта кадр алынбайды: карточкаға экранда бекітілген фото қосылады.

Келесі қатысушыға ауысқанда уақытша фото мен есім тазартылады. Бұрын құрылғыға жүктелген PNG файлдары сақталады.

Болжамдар — ойын мәтіндері; олар кездейсоқ таңдалады, адамның бет-жүзін немесе мінезін бағаламайды.

## Файлдар және өңдеу

| Файл | Мақсаты |
| --- | --- |
| `index.html` | Толық сайт: HTML, CSS, JavaScript, логотип және болжамдар |
| `README.md` | Жүктеу және қолдану нұсқаулығы |
| `.nojekyll` | GitHub Pages үшін статикалық жариялау белгісі |

Орнату, құрастыру немесе API кілті қажет емес. `.nojekyll` — бос қосымша файл; Mac Finder оны көрсетпесе де, осы бір HTML беті онсыз жұмыс істейді.

Мәтіндерді өзгерту үшін `index.html` ішіндегі `WISHES` массивін өңдеңіз. Карточка дизайны — `renderStoryCard`, фото түсіру — `captureCamera`, кадр пішімі — `normalisePhoto` функцияларында.

Камераны тексеру үшін GitHub-тағы код көрінісін емес, **Visit site** арқылы ашылған HTTPS сайтты пайдаланыңыз. Нақты камераның жұмысы құрылғы мен браузер рұқсатына байланысты.
